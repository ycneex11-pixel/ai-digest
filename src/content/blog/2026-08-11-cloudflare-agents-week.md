Cloudflare опубликовала итоги **Agents Week** — пяти дней анонсов с 3 по 7 августа, посвящённых AI-агентам. Компания рассматривает агентов как новый класс программного обеспечения. Ему нужна отдельная инфраструктура в шести областях: **идентификация, коммуникация, оркестрация, память, наблюдаемость и безопасность**.

Базовый слой — среда выполнения. **@cloudflare/computer** — новый runtime для агентов, который выбирает подходящее окружение под конкретную задачу. Python- и JavaScript-воркеры теперь взаимодействуют между собой. Workers получили поддержку **TCP-соединений и gRPC**, расходы отслеживает **Billable Usage API**. Для разработки Cloudflare вводит **ADLC** (Agent Development Lifecycle) — методологию доведения агентов до продакшена на замену SDLC. В неё входят трейсинг, **replay** и одобрение действий человеком в Cloudflare Agents, локальный трейсинг для Workers и программируемый CI/CD с агентом, чинящим сборку. **Cloudflare Wallets** дают агентам механизм безопасных транзакций в «агентной экономике».

Безопасность закрывают три инструмента. **Agent Access Model** — фреймворк доступа агентов к ресурсам и сервисам от имени пользователей. **WriteGuard** в закрытой бете добавляет контроль над рискованными вызовами инструментов на **MCP-серверах**. Поведение агентов отслеживает identity-aware аналитика. Платформу **Cloudflare OS** компания открыла в open source. Для «агентного интернета» показали **WebMCP** — способ делать сайты обнаруживаемыми и пригодными для агентов, пока в превью. **Kitesurf** — браузер для агентов на V8-изолятах в Workers, рассчитанный на меньшее потребление памяти и CPU. **MCPv2** — переписанный протокол, который упрощает развёртывание и масштабирование агентных приложений. Данные индексирует **AI Search**, интернет-статистику анализирует **Radar Researcher**.

Для команд, которые строят агентные приложения, а не чат-ботов, стек меняют четыре анонса. Runtime с выбором окружения и связка Python и JavaScript сокращают собственную оркестрацию сред. WriteGuard и Agent Access Model закрывают авторизацию вокруг MCP, которую раньше приходилось писать самим. Wallets добавляют агентам транзакции как готовый примитив. Объединение **Workers AI и AI Gateway** в единый control plane — «one binding, one wallet, one dashboard» — уменьшает интеграционный код. Остальное — шаги для экосистемы: **1 млн долларов** на open source в течение двух лет, программы Ambassadors и **Community Engineers** для мейнтейнеров.
