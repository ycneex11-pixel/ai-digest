Anthropic выпустила Claude Opus 4.7 — 16 апреля 2026 года. Модель доступна в продуктах Claude, через API, в Amazon Bedrock, Google Cloud Vertex AI и Microsoft Foundry. Идентификатор в API — `claude-opus-4-7`. Цена та же, что у Opus 4.6: $15 за 1M входных токенов и $75 за 1M выходных. Обновлён токенизатор — модель иначе разбивает текст. Это влияет на скорость и стоимость запросов с большим контекстом.

По бенчмаркам Opus 4.7 обходит Opus 4.6 и уступает Claude Mythos Preview. Anthropic объясняет порядок релиза безопасностью: компания сначала обкатывает новые меры защиты на менее способной модели. Во время обучения Opus 4.7 команда целенаправленно снижала его кибер-возможности. Полный разбор — в Opus 4.7 System Card, документ Anthropic опубликовала вместе с релизом. Там же — замеры на SWE-bench Verified и GPQA Diamond.

Для Claude Code Opus 4.7 с 23 апреля стал моделью по умолчанию. Пользователи Pro-плана фиксируют особенность: один промпт в plan mode плюс один в build mode могут выбрать 4-часовой лимит. Обсуждения идут в форумах разработчиков и в Reddit-треде GitHub Copilot. В сообществе `/r/claudeaicommunity` появились посты про «AI shrinkflation» — по отдельным замерам Opus 4.7 тратит меньше тактов на «размышление» при той же цене. Anthropic в обсуждениях пока не ответила.

Короткая сводка отличий от Opus 4.6.

- Новый токенизатор, другое разбиение текста.
- Цена та же: $15 за 1M входа, $75 за 1M выхода.
- Прирост на SWE-bench Verified и GPQA Diamond.
- Отдельный System Card с замерами безопасности.
- Доступ через Claude, API, Bedrock, Vertex AI, Foundry.
- В Claude Code — модель по умолчанию с 23 апреля.

Кому имеет смысл переход. Командам, которые упираются в точность Opus 4.6 на агентских задачах и сложных рефакторингах кода. Проектам с пином `claude-opus-4-6` через API — старый снапшот продолжит работать, Anthropic не подменяет модели автоматически. Переход на 4.7 — явный выбор на стороне разработчика. Для тестов достаточно поменять идентификатор модели в запросе и прогнать свой регрессионный набор.
