Meta выпустила бета-версию **Muse Code** — кодинг-агента, который работает в терминале и конкурирует с **Claude Code** от Anthropic и **Codex** от OpenAI. Агент построен на модели **Muse Spark 1.2** — третьем релизе подразделения Superintelligence Labs, основанного в июне 2025 года. По словам Марка Цукерберга, Muse Code выполняет полные инженерные задачи в крупных репозиториях: планирует изменения, пишет код и проверяет результат. Ранее Meta признавала, что Spark отстаёт в программировании, — релиз 1.2 закрывает этот разрыв.

The Register описывает Muse Code как «оркестратор агентов»: крупную задачу он разбивает на части и раздаёт **параллельным суб-агентам**. Каждый работает в изолированном **git worktree**, поэтому изменения не конфликтуют. Цукерберг подчёркивает: «ваша рабочая копия никогда не затрагивается». Координацию обеспечивают фоновые агенты, которые ведут общие файлы контекста. Каждое действие сначала записывается в **локальный журнал событий** и только потом выполняется — после сбоя работа не теряется. В тестах Meta система одновременно собрала **шесть фич для игры** без коллизий между агентами.

Muse Spark 1.2 — мультимодальная модель с контекстом **1 млн токенов**: принимает текст, изображения, видео, аудио и PDF. Тариф — **$1,25 за миллион входных** и **$4,25 за миллион выходных токенов**. На бенчмарках **Terminal-Bench 2.1** и **DeepSWE 1.1** Meta сравнивает модель с Opus 5, GPT-5.6 Terra, Grok 4.5 и Gemini 3.6. По данным компании, результаты моделей «плотно сгруппированы», а Muse Spark «близка к лучшим». В тесте оптимизации ядра агент сделал **больше 1000 вызовов инструментов за 24 часа** и продолжал улучшать код после начальной фазы исследования. AI-руководитель Meta Александр Ванг делает ставку на экономику: Muse Code, по его словам, «исключительно хороший вариант, особенно с точки зрения стоимости».

Модель закрытая: веса не публикуются, инференс работает в облаке Meta. Бета ставится одной командой curl, доступ открыт напрямую через API и через **OpenRouter**. На вопрос об открытой публикации весов Цукерберг ответил, что «скоро поделится подробностями».
