Мы наконец распробовали новый CLI-инструмент от Anthropic — Claude Code. Это программа для терминала, которой ставишь задачу на обычном языке, а дальше она сама разбирается: читает файлы проекта, ищет нужный код, правит его и запускает тесты.

## Что нас зацепило

Первое, что бросается в глаза, — это не автодополнение и не подсказки в духе редакторских плагинов. Claude Code ведёт себя как агент: получает задачу, строит план и выполняет его шагами, без подтверждения на каждую мелочь. Мы попросили его найти причину падения тестов в незнакомом репозитории — инструмент прошёлся по кодовой базе, нашёл проблемную миграцию и сам предложил исправление вместе с коммитом.

Отдельно порадовало, что Claude Code учитывает контекст всего проекта: структуру папок, стиль кода, зависимости. Правки вписываются в существующий код, а не торчат инородным куском, будто их написал человек из команды, а не робот со стороны. При этом инструмент не молчит о своих действиях — по шагам показывает, что делает и почему, так что контроль над процессом не теряется.

## Где это пригодится

Инструмент работает прямо из терминала — не нужно ставить отдельную среду разработки или переключаться между окнами. Нам это удобно в первую очередь для рутины: миграции между версиями библиотек, разбор чужого кода, написание тестов задним числом. Здесь ИИ экономит именно то время, которое обычно уходит не на творческую часть работы, а на механическую.

Есть и более практичный сценарий — встраивание в CI/CD и скрипты сборки. Claude Code запускается локально, подключается к API Anthropic и не требует графического интерфейса, поэтому его можно вызывать прямо из пайплайна.

Расширения для VS Code и JetBrains тоже есть, но, судя по всему, это надстройка над CLI, а не замена ему. Логика та же: терминал остаётся основным местом работы, а редактор — просто ещё одним окном рядом. Мы планируем попробовать инструмент на задачах покрупнее и посмотреть, как он себя поведёт за пределами тестового прогона.
