DeepSeek 17 октября 2026 года выпустила **DeepSeek-V4.1-Flash-1017** — обновление модели V4.1-Flash. Суффикс 1017 в названии совпадает с датой выпуска. Модель уже работает на сайте, в приложении и в API. **Открытые веса** опубликованы на Hugging Face и ModelScope в репозитории `deepseek-ai/DeepSeek-V4.1-Flash-1017`. Компания заявляет три изменения относительно предыдущей версии: **выше результаты бенчмарков, быстрее выполнение задач, короче ответы**. DeepSeek называет релиз улучшением по Парето: модель не стала хуже ни по качеству, ни по стоимости, а выиграла в обоих.

Подтверждение в анонсе — только графики. На них результат **DeepSWE v1.1 Pass@1** сопоставлен со стоимостью одной задачи, замер сделан в обвязке mini-swe-v2. Такой график показывает не только долю решённых задач, но и цену каждой из них. Числовых значений в тексте страницы нет, предыдущая версия по имени не названа. **Это данные самой DeepSeek**: независимых замеров в анонсе нет, и оценить величину прироста по нему нельзя. Пока выводы о приросте опираются только на заявления вендора.

Новую версию доучивали **обучением с подкреплением на собственной обратной связи модели**. Цель — сборка проектов целиком, а не отдельных функций. Компания описывает это как сквозную разработку проекта. DeepSeek показывает четыре примера. Это 3D-модель Запретного города, браузерная гоночная игра, воссоздание Portal 2 на движке Godot и 3D-сцена «Valley of Ages» со сменой исторических эпох. Это демонстрации, метрик по ним в анонсе нет. Модель оптимизирована под **DeepSeek Harness**, Tencent CodeBuddy и WorkBuddy. Для Harness компания рекомендует версию v0.2.1-rc.1 или новее.

Второй анонс касается поиска. **Search и Fetch API** открыты всем пользователям. Они работают на собственном поисковике DeepSeek, который, по словам компании, обрабатывает сотни миллионов запросов в день по всему миру. Цена — **$0,75 за 1000 вызовов на каждый эндпоинт**. Вызовы через серверные инструменты в DeepSeek Harness, Claude Code и Codex для пользователей DeepSeek API пока бесплатны. **Оплата начнётся 31 октября 2026 года в 16:00 UTC**. Для прямых вызовов API вне этих сред такого исключения в анонсе нет. Документация — в разделе API Guides, Search & Fetch.
