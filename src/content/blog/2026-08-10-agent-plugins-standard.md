Vercel вместе с OpenAI, Microsoft, AWS, GitHub и Anysphere (разработчик Cursor) представила **Agent Plugins 1.0.0** — открытый стандарт расширений для AI-агентов. Анонс опубликован 6 августа 2026 года. Один пакет объединяет **Agent Skills** — переиспользуемые инструкции для агента — и конфигурацию **MCP-серверов**, которые подключают внешние инструменты и сервисы. Формат на старте поддерживают шесть клиентов: **ChatGPT, Codex, Cursor, GitHub Copilot, Kiro и VS Code**.

Плагин — это директория с манифестом **plugin.json** в корне. Обязательных полей два: версия схемы и имя. Рядом лежат папка `skills/` со скиллами и файл `mcp.json` с конфигурацией серверов. Расширения под конкретный клиент выносятся в отдельные пространства имён вида `com.example.client` и не влияют на общий контракт. Стандарт намеренно минимален. Он не переопределяет существующие спецификации Skills и MCP, а описывает, как клиент находит оба типа компонентов в одном пакете. Установка, распространение и пользовательский интерфейс остаются на усмотрение клиентов — совместимый клиент лишь проверяет `plugin.json` и валидирует компоненты независимо.

Стандарт решает проблему фрагментации. Сейчас авторы адаптируют один и тот же компонент под форматы нескольких клиентов: у каждого свои метаданные верхнего уровня и пути конфигурации. С Agent Plugins **один пакет работает во всех совместимых клиентах без переупаковки**. Для авторов MCP-серверов это единая точка дистрибуции вместо отдельных сборок под каждый инструмент. Управление проектом коллективное: в технический комитет входят представители AWS, Cursor, Microsoft, OpenAI и Vercel. Спецификация опубликована на agent-plugins.org, процесс изменений идёт в публичном репозитории на GitHub. Авторы подчёркивают, что **«ни одна компания не управляет направлением развития»**.

Заметное отсутствие в списке — **Anthropic**. Компании нет ни среди мейнтейнеров, ни в перечне поддерживаемых клиентов, Claude и Claude Code в анонсе не упоминаются. При этом Claude Code распространяет те же типы компонентов — скиллы и MCP-серверы — через собственный формат плагинов. О совместимости с ним в документе ничего не сказано. В итоге стандарт, заявленный как мультивендорный, на старте обходится без разработчика Claude. Реестра или маркетплейса плагинов в анонсе тоже нет: спецификация фиксирует формат пакета, а каналы распространения каждый клиент выбирает сам.
