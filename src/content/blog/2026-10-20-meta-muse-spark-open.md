Meta опубликовала веса **Muse Spark Open** 15 октября 2026 года. В сентябре флагман Muse Spark 1.3 вышел только через API, а открытой оставалась 30-миллиардная **Muse Glimmer** под Apache 2.0. Теперь открыта модель флагманского класса: **816 млрд параметров, из них 42 млрд активных**, контекст **1 млн токенов**. Модель нативно мультимодальная. Meta обучала её под программирование и агентную работу: длинные задачи, сложную разработку, многошаговые рассуждения.

Главная практическая деталь — **запуск на двух Mac Studio с M5 Ultra**. Модель оптимизирована под свежую версию **MLX**, фреймворка Apple. В каждой машине GPU может использовать до 512 ГБ унифицированной памяти, пропускная способность памяти — 1,2 ТБ/с. Вместе две машины дают около терабайта памяти. В какой точности 816 млрд параметров помещаются в этот объём, Meta в анонсе не уточняет. Модель проверяли в двух сценариях. Через Muse Code она вносила изменения в iOS-код Ice Cubes, открытого клиента Mastodon. В DaVinci Resolve она покадрово просматривала видео.

Для серверного запуска заявлены **SGLang, vLLM, TensorRT-LLM, Hugging Face Transformers, MLX, llama.cpp и Unsloth**. Оптимизации есть для чипов AMD, Apple, Intel и NVIDIA. Дообучение идёт через PyTorch, включая TorchTitan. Meta написала для SGLang собственные ядра на Helion: ускорение на уровне отдельных ядер — 1,03–3,95× на GPU NVIDIA и AMD. В сквозном замере на **AMD MI350 прирост — 3%**. Веса лежат на Hugging Face, в Amazon SageMaker AI, Google Cloud Model Garden и Microsoft Foundry. Через API модель дают Baseten, Fireworks AI, Groq, Modal, Nebius, OpenRouter и Together AI.

Перед использованием стоит учесть три оговорки. Первая — **лицензия Muse Model License**, а не Apache 2.0, как у Glimmer. Meta описывает её условия как «ограниченные коммерческие», бесплатные для многих разработчиков. Условия нужно читать до встраивания модели в продукт. Вторая — формулировка Meta: «**самая способная открытая модель из США**». Сравнение ограничено американскими моделями, с открытыми моделями других стран Meta себя в этой фразе не сравнивает. Третья — **цифр бенчмарков в анонсе нет**: Meta ссылается на отдельный отчёт о методике, а полный отчёт об оценке обещан позже. Пока это заявления вендора без независимой проверки. По безопасности Meta сообщает о дополнительном пост-обучении и о прохождении порогов своего Superintelligence Scaling Framework. Карточка модели опубликована на Hugging Face.
